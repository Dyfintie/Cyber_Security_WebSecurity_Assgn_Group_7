Fix: Allow-list regex + Parameterized Argument Vector (shell=False).

Root Cause (Table 2 (c))
Why this vulnerability exists:
1. Direct Concatenation: User input from the HTTP request is concatenated directly into a system command string without sanitization or type constraint.
2. Shell Interpreter Invocation: The process is invoked with shell=True, delegating execution to the system shell (/bin/sh -c). The shell parses metacharacters such as ;, &, |, and $() as command delimiters rather than literal text.
3. In-Band Leakage: Both standard output (stdout) and standard error (stderr) of the spawned child process are piped directly into the HTTP response returned to the client, providing immediate visibility of the injected command's output.
Other Mitigations from Lecture Slides (Table 2 (e))

As required by the assignment guidelines, the following 4 defense strategies from the course slides protect against OS command injection:

Mitigation Strategy Mechanism of Action Why It Works
1. Avoid the Shell (Native APIs) Use native programming language libraries (e.g. Python socket, scapy, or ping3) instead of calling OS shell utilities. Completely eliminates OS command execution from the codebase. No shell process or external binary is ever invoked.
2. Parameterized Execution (Argument Vector) Pass binary name and arguments as a discrete list/array (e.g., subprocess.run(["ping", "-c", "2", target], shell=False)). Arguments are passed directly to the kernel execve system call. Shell metacharacters are treated purely as literal byte values and never parsed as syntax.
3. Allow-list Validation Validate incoming input against a strict whitelist pattern (e.g., regex ^[a-zA-Z0-9.-]+$ or IP validation) before processing. Rejects any unexpected input containing characters like ; & | ` $ > < \n \r before it ever reaches execution logic.
4. Principle of Least Privilege & Sandboxing Run the web process under a dedicated unprivileged system account (e.g., www-data) in a chroot jail, AppArmor/seccomp profile, or container. Even if an attacker achieves arbitrary command execution, their permissions are restricted, preventing privilege escalation and access to sensitive files.
